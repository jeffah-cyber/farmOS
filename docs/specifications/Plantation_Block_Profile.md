# Plantation Block Profile

## Purpose

A Plantation Block is the primary operational unit within an estate.

Every field activity, harvest and inspection is linked to a plantation block.

## Core Information

- Block Name
- Block Code
- Estate
- Crop
- Variety
- Area (ha)
- Tree Count
- Planting Date
- Current Age
- Health Status
- Supervisor

## Operational Metrics

- Active Tasks
- Last Harvest
- Estimated Yield
- Missing Trees
- Disease Reports

## Relationships

Estate
 └── Plantation Block
      ├── Field Activities
      ├── Harvests
      ├── Workers
      └── Machinery
