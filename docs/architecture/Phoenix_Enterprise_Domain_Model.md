# Vision

Phoenix OS is an Agricultural Enterprise Operating System designed to manage agricultural businesses from holding company level down to individual trees, livestock, warehouses and processing facilities.

# Core Principles

1. Every operational record belongs to an Operating Company.

2. Every operational record belongs to an Estate.

3. Every agricultural activity belongs to a Plantation Block.

4. Financial reporting aggregates upward.

Block → Estate → Company → Holding Company

5. Operational dashboards aggregate downward.

Holding Company → Company → Estate → Block
